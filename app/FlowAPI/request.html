VideoStudio · Flow request

Bản thử độc lập. Request dùng phiên Flow trong Chrome thường; không thay đổi job video đang chạy.

1. Kết nối Chrome

Reload extension VideoStudio hiện có từ extensions\videostudio-chatgpt. Mở Flow, đăng nhập rồi bấm icon extension VideoStudio để chọn tab và nhập mã kết nối.

Đang kiểm tra…

2. Gửi request

Thử “Liệt kê dự án” trước. Với thao tác có dự án, giữ tab Flow đã chọn ở đúng dự án đó.



Nếu Flow từ chối request, mã lỗi sẽ được hiển thị. Timeout/mất kết nối giữ nguyên ID để kiểm tra; không tự gửi lại hay chuyển sang bấm UI.
